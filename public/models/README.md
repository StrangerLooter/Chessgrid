# 3D GLB Models Directory

Place your custom 3D model files (`.glb` / `.gltf`) in this directory:
- e.g. `public/models/chessboard.glb`
- e.g. `public/models/chess_pieces.glb`

Once placed here, Vite and React Three Fiber (`useGLTF('/models/chessboard.glb')`) will automatically serve and load them in the 3D scenes.
